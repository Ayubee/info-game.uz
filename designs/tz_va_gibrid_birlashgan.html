RASMIY TEXNIK TOPSHIRIQ (TZ) & ARXITEKTURA REJASI

Loyiha: info-game.uz / wiki-game.uz | Ko'p tilli (UZ/RU/EN) O'yin Ensiklopediyasi, Yangiliklar Portali & Kelajakdagi Mobil Ilovalar

Hujjat Versiyasi: v1.0 Final
Holati: Tasdiqlash Arafasida
Sana: 2026-yil, Oktyabr
📋 1. ASOSIY TALABLAR VA MODULLAR
1.1. Multi-Game Tizimi: Faqat bitta o'yin (Raft) bilan cheklanmaydi. Rust, Minecraft, Cyberpunk, CS2 kabi yangi o'yinlar bazasi qulay qo'shiladi.
1.2. Ko'p Tillilik (i18n): Sayt 3 ta tilda to'liq ishlaydi:
• 🇺🇿 O'zbek tili (Lotin / Kirill)
• 🇷🇺 Rus tili (Русский)
• 🇬🇧 Ingliz tili (English)
Foydalanuvchi bir marta tanlagan til saqlanadi (`/uz/games/...`, `/ru/...`).
1.3. Wiki & Ensiklopediya Moduli: Ierarxik daraxt-menyu, buyumlar, resurslar, retseptlar, xaritalar, parametrlar, infobokslar.
1.4. O'yin Yangiliklari & Patch Notes: O'yin relizlari, yangilanishlar, e-sport va o'zbek geymerlari uchun maqolalar.
1.5. Kengaytirilgan Admin Panel:
• Yangi o'yin, kategoriya va maqolalar qo'shish
• 3 tildagi tarjimalarni yonma-yon kiritish (Tabs)
• Rasm va media fayllarni yuklash & optimizatsiya (WebP)
• Rol tizimi: SuperAdmin, Moderator, Tarjimon.
⚙️ 2. TEXNOLOGIYALAR TAXLILI & TAQQOSLASH
Quyida 3 xil zamonaviy arxitektura tahlil qilindi:
Stack SEO & Tezlik Mobil Ilovaga Mosligi Tavsiya
1. Next.js 15 + TypeScript + PostgreSQL 100 / 100 (Eng yuqori) A'lo (REST API tayyor) ⭐⭐⭐⭐⭐ Eng Tavsiya Qilinadigani
2. Laravel 11 (PHP) + Vue.js (Nuxt) 85 / 100 (Yaxshi) Yaxshi (Sanctum API) ⭐⭐⭐⭐ Kuchli admin panel uchun
3. Astro + Fastify 95 / 100 (Statik) O'rtacha ⭐⭐⭐ Faqat o'qish uchun yaxshi
Nima uchun Next.js 15 (TypeScript) Tanlandi?
1. SEO Giganti: O'zbekistonda o'yin ma'lumotlarini qidirganda Google/Yandexda 1-o'rinda chiqish uchun Server-Side Rendering (SSR) juda zarur.
2. Yagona Til: Frontend va Backend bir xil TypeScript'da yoziladi, xatolar soni kamayadi.
3. Admin Panel: Shadcn UI yoki Tailwind UI orqali dunyo darajasidagi qulay admin panel yig'iladi.
📱 3. MOBIL ILOVA (iOS & ANDROID) STRATEGIYASI
Kelajakda saytni mobil ilovaga aylantirish uchun hozirdan poydevor qo'yiladi:
3.1. Headless API-First Arxitektura:
Backend ma'lumotlarni HTML qilib emas, balki standart JSON REST API formatida qaytaradi.
• `GET /api/v1/games`
• `GET /api/v1/games/raft/wiki/titanium_ingot?lang=uz`
• `GET /api/v1/news?limit=10`
Natijada sayt ham, kelajakda iOS va Android ilovalar ham aynan bitta bazadan va bitta API'dan oziqlanadi!
3.2. Mobil Ilova Uchun Tanlov: FLUTTER (Dart)
• Bitta kod bazasi: Bitta kod yoziladi, ham iOS (App Store), ham Android (Google Play)da 120 FPS'da uchadi.
• Oflayn Rejim (Offline Wiki): Geymerlar internet bo'lmaganda ham retsept va koordinatalarni ko'ra oladi (Hive / Isar DB).
• Push-xabarlar: Yangi patch chiqqanda telefonlarga darhol bildirishnoma boradi.
